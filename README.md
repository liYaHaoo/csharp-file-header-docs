# C# File Header Docs (`csharp-file-header-docs`)

> 专为 C# / .NET / Avalonia 等项目打造的代码文件头中文注释规范 Skill。

本 Skill 旨在指导开发者与 AI 编程代理（如 OpenAI Codex、Claude Code、Cursor 等）在新建或脚手架生成 `.cs` 源代码时，自动在文件顶部插入标准化、精炼且富含架构价值的三段式中文文件级说明注释（**用途** / **定义** / **说明**）。

---

## 🌟 规范格式

在源文件的保留标记（如 License、`// <auto-generated />`）之后，以及首个 `using` 或 `namespace` 之前，插入 2~3 行精炼注释：

```csharp
// 用途：<一句话说明该文件在系统/项目中的架构角色与业务目标>。
// 定义：<主要类型/接口/记录/枚举名称及其核心职责>。
// 说明：<可选的使用约束、生命周期(Singleton/Scoped)、并发/线程安全或设计约束>。
```

> **注意**：没有关键约束时可省略 `说明`。注释描述使用中文，类型名/API/协议名保持代码原样。

---

## 📖 示例参考

### 1. 服务接口契约
```csharp
// 用途：定义 UI 和编排层使用的配方操作应用边界。
// 定义：IRecipeService，用于查询、创建和更新配方的服务契约。
namespace MyApp.Application.Services;
```

### 2. UI 视图模型 (ViewModel)
```csharp
// 用途：协调 Avalonia UI 主窗口的展示状态和用户交互命令。
// 定义：MainWindowViewModel，暴露给 MainWindow 的数据上下文。
// 说明：这里只保留 UI 状态与命令转发，业务编排委托给应用服务。
```

### 3. 不可变数据契约 (Record / DTO)
```csharp
// 用途：表示列表和搜索视图中展示的配方摘要。
// 定义：RecipeListItem，配方标识和展示元数据的不可变投影。
```

### 4. 应用程序入口 (Program.cs)
```csharp
// 用途：应用程序入口点，配置宿主环境、依赖注入容器与 Avalonia 生命周期。
// 定义：顶层引导流程，初始化服务并启动主界面。
// 说明：所有基础服务在此集中注册，异常退出时触发全局资源清理。
```

## 🚀 安装与跨电脑使用指引

无论您在家里、公司还是云端开发机，只需通过以下方式之一即可快速接入该 Skill：

### 方式一：Codex 全局安装（推荐个人开发机，所有项目通用）

**A. 使用 Codex 官方安装器（推荐）**
```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py --repo liYaHaoo/csharp-file-header-docs
```

**B. 直接 Git Clone**
```bash
git clone https://github.com/liYaHaoo/csharp-file-header-docs.git ~/.codex/skills/csharp-file-header-docs
```
安装后，Codex 在任何 C# 项目中新建 `.cs` 文件时均可直接激活使用。

---

### 方式二：团队项目级集成（推荐团队仓库，随工程自动分发）

直接将此规范内置于项目仓库中，团队成员或 CI 协同开发时无需单独配置环境：

**A. 作为 Git Submodule 引入（推荐）：**
```bash
mkdir -p .agents/skills
git submodule add https://github.com/liYaHaoo/csharp-file-header-docs.git .agents/skills/csharp-file-header-docs
```

**B. 软链接或直接复制：**
```bash
# 如果本地已有该仓库：
ln -s /path/to/csharp-file-header-docs .agents/skills/csharp-file-header-docs
```

---

### 方式三：与 CC-Switch / Claude Code 集成

如果您使用 CC-Switch 管理技能工具：
```bash
ln -s /path/to/csharp-file-header-docs ~/.cc-switch/skills/csharp-file-header-docs
```
