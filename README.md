# C# 工业视觉项目工程规则与协作准则 (`csharp-vision-project-rules`)

> 专为 C# / .NET / Avalonia / WPF 工业视觉、图像采集与自动化检测项目打造的工程规范与 AI 协作契约 Skill。

本 Skill 旨在指导开发者与 AI 编程代理（如 OpenAI Codex、Claude Code、Cursor 等）在进行机器视觉项目开发时，严格遵守工业级的高可靠架构规约、零拷贝内存管理、UI 离屏渲染与源码元数据注释规范；同时支持在目标项目本地一键初始化生成定制化的 `AGENTS.md` 行为准则文件。

---

## 🌟 核心能力矩阵

1. **工业视觉工程规约**：
   - **硬件抽象层 (HAL)**：相机（Hikvision / Basler / FLIR / 大恒）、光源、PLC 的接口抽象与断线重连隔离；
   - **零拷贝与 GC 防护**：`ArrayPool<byte>` 内存复用、`Span<T>` / `Memory<T>` 切片传递，避免采集高频循环引发 Gen 2 GC 停顿与丢帧；
   - **UI 离屏解耦**：计算与渲染分离，UI 线程仅拉取最新渲染帧并执行跳帧保护，严禁阻塞 UI 调度器；
   - **原生互操作安全**：`OpenCvSharp` / `Halcon` / `P/Invoke` 原生资源显式实现 `IDisposable`，杜绝句柄泄漏。
2. **源码级元数据契约**：
   - 继承并规范化 C# 源码文件头三段式中文说明（**用途** / **定义** / **说明**），置于首个 `using` 前，清晰阐明架构角色与设计约束。
3. **AI 协作行为准则**：
   - 尊称“老大”、Think in English / Answer in Chinese、保留原始代码符号大小写；
   - 只读优先、保护已有工作区改动、严禁未经明确授权执行 Git 变更/高危硬件交互/文件删除；
   - 单问原则与最低构建交付门禁（`dotnet build` 耗时与 Error/Warning 汇报）。
4. **一键生成本地 `AGENTS.md`**：
   - 内置自动化探测与模板注入脚本，秒级在项目根目录生成定制化行为准则。

## 🚀 快速使用

### 1. 本地一键生成 `AGENTS.md`

在任意 C# 视觉工程根目录下运行脚本：

```bash
# 在当前工作区生成 AGENTS.md（自动探测当前项目的 .NET 版本、UI 框架与视觉库）
python3 /Users/yahaoli/plugins/skills/csharp-vision-project-rules/scripts/init_agents_md.py .

# 若目标工作区已存在 AGENTS.md，可使用 --force 强制覆盖更新
python3 /Users/yahaoli/plugins/skills/csharp-vision-project-rules/scripts/init_agents_md.py /path/to/project --force
```

### 2. 源码文件头标准格式

在源文件的保留标记（如 License、`// <auto-generated />`）之后，以及首个 `using` 或 `namespace` 之前插入：

```csharp
// 用途：<一句话说明该文件在系统/项目中的架构角色与业务目标>。
// 定义：<主要类型/接口/记录/枚举名称及其核心职责>。
// 说明：<可选的使用约束、生命周期(Singleton/Scoped)、并发/线程安全或设计约束>。
```

## 📖 视觉典型场景文件头示例

### 1. 硬件抽象接口 (HAL)
```csharp
// 用途：定义工业相机的通用硬件抽象契约，屏蔽底层厂商驱动差异。
// 定义：ICameraDevice，提供跨厂商相机的连接、采图参数配置与流捕获事件。
// 说明：实现类必须保证 Open/Close 的幂等性，采图回调严禁阻塞。
namespace MyVisionApp.Hardware.Camera;
```

### 2. 零拷贝缓冲池
```csharp
// 用途：管理高分辨率工业相机原始图像帧的内存复用与生命周期。
// 定义：ImageBufferPool，基于 ArrayPool<byte> 的零拷贝图像内存池实现。
// 说明：注册为 Singleton，所有租借的 MemoryBuffer 必须在算法消费完毕后显式归还。
```

### 3. UI 视图模型 (ViewModel)
```csharp
// 用途：协调 Avalonia UI 实时检测画面的渲染状态与相机控图交互。
// 定义：CameraPreviewViewModel，驱动检测画面与缺陷标注遮罩的数据上下文。
// 说明：采用跳帧队列接收检测结果，只通过 WriteableBitmap 向 UI 线程投递最新渲染帧。
```
